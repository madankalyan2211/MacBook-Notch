# 🍏 MacBook Notch — Dynamic Island for macOS

Bring Apple's iPhone Dynamic Island to your MacBook notch with live music controls, call HUDs, voice memos, clipboard history, and system status.

---

## 🚀 How to Install & Start on Another Mac

### 1. Download / Receive the Installer
Send the **`MacBookNotch.dmg`** file to the other Mac (via AirDrop, Google Drive, Slack, etc.).

### 2. Install
1. Double-click **`MacBookNotch.dmg`**.
2. **Drag `MacBookNotch` into the `Applications` shortcut folder**.

---

### 3. First-Time Start (10 Seconds)
Because the app is built locally:
1. Open your **Applications** folder in Finder.
2. **Right-click (or Control-click)** on `MacBookNotch`.
3. Click **Open**, then click **Open** in the confirmation dialog.
*(Alternatively: Open `MacBookNotch` once -> go to **System Settings > Privacy & Security > click "Open Anyway"**)*

---

## ✨ Features & Shortcuts

| Feature | Shortcut / Trigger | Description |
| :--- | :--- | :--- |
| **"hello" Signature Greeting** | **`⌥ H`** (Option + H) | Iconic animated Apple cursive signature greeting |
| **Music & YouTube Player** | Play music (Spotify / Apple Music / YouTube) | Live audio equalizer, album art, interactive scrubber |
| **Active Call HUD** | Live Call (FaceTime, WhatsApp, Zoom, Teams) or **`⌥ C`** | Live timer, microphone equalizer, mute & end call |
| **Voice Memos Recorder** | **`⌥ R`** (Option + R) | Pulsing recording indicator, waveform, pause & stop |
| **Clipboard Copy Banner** | **`⌘ C`** (Copy anything) | Auto-expanded card with preview, link opener & re-copy |
| **Do Not Disturb / Focus** | **`⌥ D`** (Option + D) | Quick focus mode switcher |
| **AirPods Connection** | **`⌥ A`** (Option + A) | AirPods battery and connection status |
| **Caps Lock Key HUD** | Press **`Caps Lock`** | Glowing LED indicator pill showing Caps Lock ON / OFF |

---

## ⚙️ Start at Login (Optional)
To make it launch automatically whenever the Mac turns on:
1. Go to **System Settings > General > Login Items**.
2. Under **"Open at Login"**, click the **`+`** button.
3. Select **`MacBookNotch`** from Applications.
